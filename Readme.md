# Simple Bible Reader 📖

This is a simple, clean desktop Bible reader application created as a **reference work and portfolio project** to demonstrate my software development and programming skills.

The purpose of the application is to provide quick access and comfortable reading of Public Domain biblical texts from a local database using an embedded lightweight browser module.

## ✨ Key Features
*   **Offline Operation:** No internet connection required; texts are loaded directly from a local database.
*   **Embedded Rendering:** HTML/CSS-based responsive text rendering for a modern user experience.
*   **Streamlined Interface:** Quick navigation between books and chapters with zero editing capabilities (Read-Only).

## 🛠️ Technology Stack
The application is built using modern, industry-standard technologies:
*   **Backend / Logic:** C# (.NET)
*   **Database Management:** SQL / SQLite (`Microsoft.Data.Sqlite`)
*   **Frontend / Presentation:** HTML, CSS, JavaScript
*   **Browser Module:** `Microsoft.Web.WebView2` (Embedded Chromium-based engine)
