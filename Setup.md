# Installation and Execution

1. Download the application from the GitHub repository:

   https://github.com/lorinczzsolt79/BibleBooksNE/releases
	
2. Extract the files into an empty directory that has write permissions.

   Example: C:\Program Files\BBNE\

   ! Note: Administrator privileges may be required to write to this folder.

3. Double-click the `BibleBooksNE.exe` file to launch the application.

   ! Note: Since the application is unsigned, Windows SmartScreen may display a "Windows protected your PC" warning. 
     To run the program, click **"More info"** and then select **"Run anyway"**.
