# Telepítés és futtatás

1. Töltse le a programot a GitHub weboldalról:

   https://github.com/lorinczzsolt79/BibleBooksNE/releases
	
2. Bontsa ki a fájlokat egy üres és írható könyvtárba.

   Például: C:\Program Files\BBNE\

   ! Figyelem: Szükséges lehet rendszergazdai jogosultság a mappa írásához.

3. Klikkeljen a `BibleBooksNE.exe` fájlra duplán a program futtatásához.

   ! Figyelem: Mivel a program nem rendelkezik digitális aláírással, a Windows SmartScreen egy „A Windows megvédte a számítógépét” figyelmeztetést jeleníthet meg. A futtatáshoz kattintson a **„További információ”** linkre, majd válassza a **„Futtatás mindenképpen”** gombot.
