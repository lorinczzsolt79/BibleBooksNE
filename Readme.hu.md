# Simple Bible Reader 📖

Ez egy egyszerű, letisztult asztali bibliaolvasó alkalmazás, amelyet **referenciamunkának és portfólió-projektnek** készítettem a programozási ismereteim bemutatására. 

A program célja a szabad terjesztésű (Public Domain) bibliai szövegek gyors elérése és kényelmes olvasása egy helyi adatbázisból, egy beépített könnyűsúlyú böngészőmodul segítségével.

## ✨ Főbb funkciók
*   **Offline működés:** Nincs szükség internetkapcsolatra, a szövegek helyi adatbázisból töltődnek be.
*   **Beépített renderelés:** HTML/CSS alapú reszponzív szövegmegjelenítés a modern felhasználói élményért.
*   **Egyszerű kezelőfelület:** Gyors navigáció a könyvek és fejezetek között szerkesztési opciók nélkül (Read-Only).

## 🛠️ Technológiai Stack
Az alkalmazás modern, jól bevált technológiákra épül:
*   **Backend / Logika:** C# (.NET)
*   **Adatbázis-kezelés:** SQL / SQLite (`Microsoft.Data.Sqlite`)
*   **Megjelenítés / Frontend:** HTML, CSS, JavaScript
*   **Böngésző modul:** `Microsoft.Web.WebView2` (beágyazott Chromium alapú motor)
