
# Html fájl elkészítése

	1.)	Üres Html sablon

			- Beolvasni a sablont külsõ fájlból

				- elsõ rész
				- cserélhetõ legyen a script rész
				- cserélhetõ legyen a style rész
				- cserélhetõ legyen a main rész
				- lezáró résszel

				html,head(script, style), body(header, main, footer)

				A H1 beállítható legyen.
				A Title beállítható legyen.
				A Footer Beállítható legyen.	(Program adatok.)

	2.)	Html fájl a weboldalakhoz
			
			-  Üres Html sablon
			-  Hozzáadni a script részt külsõ fájlból
			-  Hozzáadni a style részt külsõ fájlból

	3.)	Main rész elkészítése

			- összeadhatók legyenek egybe a különbözõ biblia sorok.

			- egy biblia sorai

				A biblia sorai mellett tartalmazza,
					 a megjelenítendõ többi részt:
						kereszthivatkozás,
						lábjegyzet,
						Headlines,
						szólista.
			
			- több biblia sorai egy fájlban

				- nincs kereszthivatkozás
				- nincs lábjegyzet
				- nincs Headlines
				- nincs szólista
