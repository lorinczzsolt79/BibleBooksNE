## Selection

	### Verses:	Get bible verses

		Bible					Selected	Database selection		from all databases that list contains, one (selected) or more (selected), all (-1)
			Table				Selected	SQL selection			from all tables that list contains, one (selected) or more (selected), all (-1)
				Book			Selected	SQL selection			from all book that list contains, one (selected) or more (selected), all (-1)
					Chapter		Selected	SQL selection			all chapters that list contains, one (selected) or more (selected), all (-1)
						Verse	All			SQL selection			all verses that list contains, one (selected) or more (selected), all (-1)
		Example:
			- Whole:			(if ids:) Bible = -1; Book = -1; Chapter = -1; Verse = -1;	where -n means ALL Bibles, ALL Books, ALL Chapters, ALL Verses
			- Full selection:	(if ids:) Bible =  1; Book =  1; Chapter =  1; Verse =  1;	where  1 means only one, only the selected

	### BookInfos:	Get bible infos

					one or more BookInfos

	### AddOns:		Get values
	
					If Order Type List contains and always ALL!

	### SQL Tables

		Identifiers					Table		Note

		Book, Chapter, Verse		Verses		If the Verse Identifier value is less then 0 means ALL verses from chapter.
												Otherwise only the matched BibleRow.

		Book						BookInfos	Where BookInfos Id equals with BibleRow.Book Id.

		Plus!						If necessary. Always ALL!

		Book, Chapter				Crosslinks	All Crosslinks for Chapter if Order Type List contains.
		Book, Chapter				Footnotes	All Footnotes for Chapter if Order Type List contains.
		Book, Chapter				Headlines	All Headlines for Chapter if Order Type List contains.
		Book, Chapter				WordList	All WordList for Chapter if Order Type List contains.
