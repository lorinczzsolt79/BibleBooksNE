# BookNames Handler

	At Start time only:

		Default setting:	User_Selection(0,0,0,0);
		User setting:		change User_Selection(1,1,1,1);

		0.	SetBibleList

			Clear Bible List if not empty.
			If Database number > 0
				Add LongBibleNames to List of Bibles
				SetSelectedBible(Bible)
			SetBookList

	At Start time and other case:

		1. SetBookList
			If User_Selection.Bible.Book number > 0
				If User_Selection.Bible.Changed
					GetBookNumbers(Bible)	AllDatabases.DBs.GetDatabase(datebase_number).BookNumbers		// int array
						Clear Bible List if not empty.
						if BookNames > 0 try to change BookNumbers to LongBookNames
							then Show BookNames in List
						else Show BookNumbers in List
						SetSelectedBook(Book)
				else
			else clear list if not empty
			SetChapterList

		2. SetChapterList
			If User_Selection.Bible.Book.Chapter number > 0
				If User_Selection.Bible.Book.Changed
					GetChapteNumbers(Bible, Book)	AllDatabases.DBs.GetDatabase(datebase_number).ChapterNumbers(Book)		// int array
						Clear Chapter List if not empty.
						Show ChapterNumbers in List
						SetSelectedChapter(Chapter)
				else
			else clear list if not empty
			SetVerseList

		3.	SetVerseList
			 If User_Selection.Bible.Book.Chapter.Verse number > 0
			 	If User_Selection.Bible.Book.Chapter.Changed
			 		GetVerseNumbers(Bible, Book, Chapter)	AllDatabases.DBs.GetDatabase(datebase_number).VerseNumbers(Chapter)		// int array
			 			Clear Verse List if not empty.
			 			Show VerseNumbers in List
			 			SetSelectedVerse(Verse)
			 	else
			 else clear list if not empty
			 ShowWebPage
