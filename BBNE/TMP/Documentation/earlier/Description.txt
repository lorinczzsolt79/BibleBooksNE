		Azonosítók:
		    Az azonosítók a következõk: biblia, könyv, fejezet, vers, sorszám, típus.
		
		Sorszám:
		    A sorszám azonosító a versek és
		    a hozzájuk tartozó bejegyzések sorrendjét mutatja
		    VAGY a footnote sorrendet.
		    
		Típus:
		    A típus azonosítók a következõk:
			none,			// 0
			chapter_title,	// 1 = egy adott fejezeteknek lehet címe;
			headlines,		// 2 = egy adott fejezeten belül is lehet alcíme;
			verse,			// 3 = maga a biblia vers;
			crosslink,		// 4 = a kereszthivatkozások felsorolása;
			footnote,		// 5 = egy lábjegzet;
							// 6
							// 7
							// 8
			wordlist = 9	// 9 = megjelölt szavak listája, fordításhoz;
